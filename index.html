Getting Started with Robotics

Welcome to Robotics 101’s documentation!

Robotics is a multidisciplinary field including electrical, mechanical, and computer engineering. At Robotics Society, we aim to teach all the fundamentals of robotics to design and operate robots.

We are going to start with software aspect before electronics and mechanics,as we believe that it is easier, and more economical to learn programming and software before moving to hardware. This documentation deals with the software aspects of robotics, including basic programming, version control, containerization, and writing documentation, like this one.

In case of any doubt, please contact us on the Robotics Society Server.
