# Getting Started with Robotics

This repository is made for begineers who want to get started with robotics, it goes into the software aspect of robotics, how to create, manage and distribute your software from scratch.
Information here is not limited in context to robotics system and is generally helpful for any kind of software project.

This guide goes into following concepts:
- Linux Operating system
- Version Control (Using Git)
- Conterisation (Using dokcer)
- Basic Programming in C

## Guide

The detailed guide has been shifted to the [robotics website](http://roboticspec.com/Getting-Started-With-Robotics/).

## Doubts
